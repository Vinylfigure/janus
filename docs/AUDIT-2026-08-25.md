## Template-specific findings

### J1 · The template is exempt from its own medicine

`CLAUDE.md` still reads NOT BOOTSTRAPPED, and the exemptions compound: `verify.sh quick`
is a no-op for `.md` files (the template's entire artifact class), so the verify-fail
signal channel is dead here; the recalibration staleness nudge in `session-start.sh` is
gated off while un-bootstrapped, so `/recalibrate` has no trigger, has never run
(no `recalibrated-at` stamp), and `sources-seen.md` is frozen at 2026-07-24 — while
`docs/MODEL-TIERS.md` and the frontmatter allowlists in `scripts/test-hooks.sh` name
`/recalibrate` as their owner. Fix: give the template a bootstrap-equivalent — wire
`verify.sh quick` to a markdown arm (issue #27 already proposes this) and un-gate the
staleness nudge, or explicitly decision-lock the exemption instead of drifting inside it.

### J2 · Manifest vs. scheduler contradiction

`.github/loops.yaml` declares `work-loop` and `maintenance` as `enabled: false`, and the
fleet-status dashboard (issue #31) renders "declared, not armed" — while the work-loop
trigger (`trig_01AW29SzxbUySGqfKNkh23G1`, recorded in issue #23) has been live and
firing 4×/day since 2026-08-17. `scripts/check-loops.sh` is detect-only and cannot see
the live scheduler, so the two sources of truth diverged silently. Fix: update
loops.yaml arming state whenever a routine is armed/disarmed (make it part of the arming
runbook in #23), and have the roster reconcile in overlord flag the diff.

### J3 · The work-loop fires but cannot consume this backlog

~20 firings since the last `task/<n>` delivery (PR #40, 2026-08-20), against seven
9-day-old open tasks. The likely cause is structural, not a fault: the remaining backlog
is dominated by operator-only paths the headless permission preflight correctly refuses
(#26 settings.json, #27 hooks/verify machinery, #25 gate-bearing skills + fixtures, #19
recalibrate — blocked by J1, #20 operator-run experiment, #28 `loop:hold`). Fix: label
operator-gated tasks so the loop skips them without re-judging 4×/day, surface them in
overlord's operator-actions list, lower the cadence until consumable work exists, and
adopt the no-silent-firing contract (portfolio report F2) so every firing states which
arm ran.

### J4 · Consolidation and efficacy

21 Evidence-1 candidates are 32–50 days stale; `scripts/check-ledger-aging.sh` always
exits 0 and its list appears nowhere the operator must look (session-start prints only
the ripe count — currently 1, L-044). 9 of 23 promotions used the Evidence-1
user-confirmation hatch. Scope discipline has inverted: 57/58 entries marked `portable`
against a default-`project` rule (39/39 at the 08-16 audit; worse since) — the scope
census (#18) is overdue. Deepest: L-037's baseline experiment (#20) has never run and
its `observed:` note records the first interim data point as negative ("the loop did not
survive replication"). The efficacy pass carries ~4 `observed:` notes total. Fix: run
the #20 experiment; make aging/ripe counts a consumed signal (portfolio report F4);
either enforce the scope default or change the rule to match reality.
