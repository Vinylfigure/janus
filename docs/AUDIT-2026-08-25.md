## Template-specific findings

### J1 · The template posture is deliberate — but its maintenance artifacts have no owner

**Operator ruling (2026-08-25, this audit's review): janus is a template. Its loops are
declared here and armed in the repos stamped from it — the template does not run its own
loops.** So NOT BOOTSTRAPPED, the gated-off recalibration nudge, and the unarmed
`maintenance` manifest entry are the design, not drift; an earlier draft of this audit
read them as defects and was corrected.

The residue is real, though: several template artifacts name `/recalibrate` as their
owner — the price/model table in `docs/MODEL-TIERS.md` (cached 2026-06-24), the
frontmatter allowlists in `scripts/test-hooks.sh`, `sources-seen.md` (frozen
2026-07-24) — and under the template posture nothing here will ever run it. Fix: assign
those artifacts an owner that exists — either the harvest pass (J7: children recalibrate
and the template inherits the result) or overlord's maintenance loop covering the
template explicitly — and record the posture via `/decision-lock` so the next audit
doesn't re-litigate it.

### J2 · A work-loop trigger is armed against the template, against the posture

Under the J1 ruling, `.github/loops.yaml` saying `work-loop: enabled: false` and the
dashboard rendering "declared, not armed" are *correct* for this repo. The anomaly is
the live scheduler: trigger `trig_01AW29SzxbUySGqfKNkh23G1` (recorded in issue #23) has
fired a work-loop against the template 4×/day since 2026-08-17. Either it is a
sanctioned, temporary exception for template-improvement work — then say so in
loops.yaml and the arming record so the manifest and scheduler agree — or it
contradicts the posture and should be disarmed. `scripts/check-loops.sh` is detect-only
and cannot see the live scheduler, so only the overlord-side roster reconcile can catch
this class of divergence.

### J3 · That trigger fires 4×/day and has consumed nothing in 5 days

~20 firings since the last `task/<n>` delivery (PR #40, 2026-08-20), against seven
9-day-old open tasks. Structural, not a fault: the remaining backlog is dominated by
operator-only paths the headless permission preflight correctly refuses (#26
settings.json, #27 hooks/verify machinery, #25 gate-bearing skills + fixtures, #19
recalibrate — moot under J1, #20 operator-run experiment, #28 `loop:hold`). Which
reinforces J2: template-repo work is mostly operator-only *by nature* — machinery,
hooks, CI — so a headless loop here has little it is allowed to touch. Fix: disarm the
trigger (or drop it to a low cadence) per the J2 decision; route template improvement
through operator sessions and the harvest pass; label the operator-gated tasks and
surface them in overlord's operator-actions list either way.

### J4 · Consolidation and efficacy

21 Evidence-1 candidates are 32–50 days stale; `scripts/check-ledger-aging.sh` always
exits 0 and its list appears nowhere the operator must look (session-start prints only
the ripe count — currently 1, L-044). 9 of 23 promotions used the Evidence-1
user-confirmation hatch. Scope discipline has inverted: 57/58 entries marked `portable`
against a default-`project` rule (39/39 at the 08-16 audit; worse since) — the scope
census (#18) is overdue. Deepest: L-037's baseline experiment (#20) has never run and
its `observed:` note records the first interim data point as negative ("the loop did not
survive replication"). The efficacy pass carries ~4 `observed:` notes total. Fix: run
the #20 experiment; make aging/ripe counts a consumed signal (portfolio report F4);
either enforce the scope default or change the rule to match reality.

### J5 · Sequential IDs contradict a filed learning and have already collided

L-058 (2026-08-22) rules: collision-proof IDs (date+slug), union merge driver, CI

rules, `docs/SELF-IMPROVEMENT.md`, and the reflect skill all still say "highest L-NNN
+ 1" (same for DL-NNN in `docs/DECISIONS.md`). The predicted failure already happened:
PRs #43/#44 opened 19 seconds apart from two sessions, #44 closed unmerged, its branch

Fix: adopt date+slug for new entries in reflect + writer rules; grandfather existing
IDs; delete or salvage the stranded branch.

## Disposition

Findings J1–J6 map onto the portfolio report's F2–F5/F7/F8 fixes and its ready-to-file
task drafts; J7 is the double-down. Under the template posture (J1) the shape is: the
template declares, children arm, and template maintenance flows back through harvest —
so the fixes here are one disarm-or-sanction decision (J2/J3), an ownership assignment
for the artifacts `/recalibrate` was supposed to keep fresh (J1), and the doc/ID hygiene
(J5/J6). Nothing requires new machinery.
