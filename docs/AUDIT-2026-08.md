# Audit 2026-08 — the work loop Janus never had

Provenance: 2026-08-16, branch `claude/jan-overlord-audit-1py23q`, operator-
commissioned. Method: full read of this repo; full read of overlord; ledger
harvest of six children (fillmore-v2, aegis-sentinel, DryDock, job-search,
drifthaven, home-assistant); online research (Beads/agent issue-tracking,
Claude Code plan-persistence issues, compound-engineering plugins, GitHub
Agent HQ). Sections 1–4 describe findings; section 5 lists what this branch
landed; section 6 is report-only — operator decisions, deliberately not
implemented here.

## 1. Verdict

Janus is a carefully-instrumented, well-dogfooded **knowledge** loop with an
honest self-critical record — and it had **no work loop at all**. Three loops
(edit / session / lineage) all point at knowledge; none pointed at unfinished
work. A plan's "part B" lived only in the conversation transcript and
evaporated at session end. The fleet supplied the proof (§3). This branch
closes that loop (§5) using the fleet's native store — GitHub issues — per
L-014/L-015: no new tools, only discipline.

## 2. Findings — the template itself

1. **No deferral mechanism existed.** `/plan-feature`'s template had five
   sections and no "Deferred"; zero descope vocabulary anywhere in the repo;
   `/ship` PR bodies had no follow-ups field; no skill ever filed an issue.
   `/reflect` correctly rejects work items (rules only), so the ledger could
   not catch them either. The one precedent was L-037 — a deferred work item
   parked with an explicit re-open trigger that actually fired — encoded
   nowhere. (Fixed: L-043, §5.)
2. **The template-button stamp kills child memory loops.** L-039: three of six
   children carried the un-replicated fingerprint; aegis-sentinel ran 13 PRs
   over 3 weeks with a wired-but-dead loop. Nudges alone did not revive it.
   (Fixed: retrofit mode, session-start self-check, bootstrap gate, §5.)
3. **A provisioning step wrote a verification stamp.** `/replicate` stamped
   the child's recalibration clock at birth — an L-020 false green by design;
   overlord carries exactly this bug today. (Fixed: L-045, §5.)
4. **Invisible candidates.** The session-start memory line prints only when
   ripe > 0, so 23 candidates at Evidence 1 were invisible, some for five
   weeks. Sibling ledgers are islands: L-004 has fleet-wide Evidence ≥ 6
   across three children but stood at 2 here. (Partially fixed: cross-sibling
   evidence rule L-044; candidate-aging remains open, §6.)
5. **Scope discipline never bound.** 39/39 entries marked portable, including
   four filed after the default-to-project rule landed. Every portable entry
   is copied to every child forever. (Open, §6.)
6. **The efficacy pass is nearly unused** — one `observed:` note ever, so the
   L-033 retirement path was theoretical. Counter-evidence exists downstream:
   fillmore-v2 performed the fleet's only efficacy retirement (of inherited
   L-015). The mechanism works when the loop actually runs.
7. **Platform drift went unwatched.** GitHub shipped Agent HQ (2026-02) and
   the fleet learned months late from the operator — /recalibrate has never
   completed a full run here, and its source list watched only Anthropic
   surfaces. (Fixed: GitHub changelog added to sources, L-046; the first real
   run remains open, §6.)

## 4. Platform reckoning

GitHub Agent HQ / mission control (public preview 2026-02) commoditizes the
dispatch-transport layer: parallel task assignment across repos, custom
agents via AGENTS.md, steering, branch controls, governance. Verified
absences — no goal registry, no merged-vs-objective comparison, no proposing
of next work, **no capture of deferred work as issues**, no learning loop, no
evidence-thresholded promotion, no heredity. Those absences are exactly the
layers Janus and overlord keep. Cost check: Agent HQ requires a paid Copilot
plan and meters agentic use per request; the current channel bills the
operator's existing Claude subscription. Posture adopted: **watch, don't
buy** — and don't build more transport either. AGENTS.md mirroring (CLAUDE.md
canonical, AGENTS.md generated) is recommended but not implemented here
(L-014: mechanism follows demonstrated need).
